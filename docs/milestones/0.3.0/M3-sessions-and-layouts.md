# M3：全局布局保存与会话恢复

**状态：** 待开始
**依赖：** M2
**目标：** 在 M2 全局多项目会话工作区基础上，保存布局并可靠呈现重启后的已结束会话。

## 范围

- 为 M2 的全局混合项目工作区持久化分栏树、面板比例、标签关联、焦点与自动/自定义终端标题。
- 提供默认工作区恢复及用户可选的命名布局保存/应用；布局可包含不同项目和 CLI 的 PTY 引用。
- 应用重启后不接管旧 PTY；已保存布局中的进程显示为已结束，可重新启动 CLI 或从对应项目的 CLI 历史恢复。
- 保留 PTY 会话稳定身份、项目归属、CLI 工具、工作目录、标题、运行状态和可选 CLI 对话 ID；布局 ID、CLI 对话 ID 与 PTY ID 相互独立。
- 布局树支持缺失 PTY、已删除项目、损坏数据和版本升级的降级处理；单个失效引用不得损坏其他有效面板。

## 非目标

- 不重做 M2 已验收的会话标签、拆分方向、分隔线拖动和焦点交互。
- 不提供通用拖拽式 IDE 面板系统或任意插件面板。
- 不将不同 CLI 的会话正文汇总成统一聊天记录。
- 不因布局中某个 PTY 缺失而删除项目或其他会话。

## 验收条件

- [ ] 同一工作区可保存并恢复来自至少两个项目和多个 CLI 的面板树、比例、会话标签关联与焦点。
- [ ] 保存、复制、重命名、应用或删除布局预设均不创建、移动或终止 PTY。
- [ ] 应用重启后所有遗留 PTY 都显示为已结束，不自动恢复进程；用户可在布局占位中重新启动或从 CLI 会话历史恢复。
- [ ] 删除项目或会话后只将其布局引用呈现为可修复/可移除状态，不影响其余有效面板。
- [ ] 旧版无布局数据或布局版本不兼容时回退到有效默认工作区，不损伤项目、CLI 配置或会话元数据。
- [ ] 备份、恢复与配置导入导出明确区分业务数据和工作区布局；恢复前生成保护恢复点并处理布局引用校验。

## 产物

- 全局混合项目工作区和命名布局持久化模型。
- 重启后的已结束会话占位、重新启动/恢复流程和迁移说明。

## 测试与门禁计划

- Rust：布局 schema 升级、有效/缺失/重复会话引用、项目删除、布局 CRUD、坏 JSON/版本回退和备份恢复测试；运行格式、测试与编译门禁。
- 前端：工作区持久化与恢复、会话已结束占位、拆分比例/焦点/会话 ID 恢复、失效引用修复和布局预设完整交互。
- 手工验证：保存跨项目分栏，退出应用并重启；确认进程不自动启动、布局引用正确显示已结束，并能逐个重新启动或恢复 CLI 历史。
- 手工验证：活动 PTY 退出确认、托盘隐藏、异常关闭后的进程隔离与布局恢复；覆盖损坏布局和项目移除。
- 完成差异审查、修复、复审后重新运行全部门禁；Windows 先验收，macOS/Linux 结果记入 M5 跨平台待办。
