# M3：独立会话、多面板与布局预设

**状态：** 待开始
**依赖：** M2
**目标：** 允许用户自由排列和切换各自独立的 PTY 会话。

## 范围

- 定义 PTY 会话稳定身份、项目归属、CLI 工具、工作目录、标题、运行状态和可选 CLI 对话 ID。
- 支持同一项目多个 CLI 和同一 CLI 多个独立终端。
- 支持终端标签、分栏、尺寸调整、焦点切换、重命名、关闭和重新打开。
- 布局预设只保存面板树、比例和会话引用，不代表 PTY 所有权。
- 项目切换可以恢复最近视图；用户也可显式保存和应用项目布局预设。
- 对 CLI 对话关联使用可选匹配：无法可靠识别时仍允许 PTY 独立存在。

## 非目标

- 不提供通用拖拽式 IDE 面板系统或任意插件面板。
- 不将不同 CLI 的会话正文汇总成统一聊天记录。
- 不因布局中某个 PTY 缺失而删除项目或其他会话。

## 验收条件

- [ ] 每个 PTY 独立归属一个项目和工具，CLI 对话关联允许为空。
- [ ] 可在至少两个终端间创建、分栏、调整比例、切换焦点和关闭。
- [ ] 重排或移除一个面板不会误关其他面板的 PTY。
- [ ] 保存和应用布局预设不改变 PTY 的身份、项目归属或运行状态。
- [ ] 已退出或不可恢复的会话有明确占位和重新启动/恢复入口。
- [ ] 布局数据升级与损坏时可回退到有效默认工作区，不损伤项目和 CLI 配置。

## 产物

- PTY 会话和布局持久化模型。
- 多面板 UI 与布局保存/恢复流程。
