# M2：跨项目共享终端工作台

**状态：** 进行中（Windows 工作台开发）
**依赖：** M1
**目标：** 将主窗口改为以项目归属和跨项目 PTY 会话为中心的共享工作区。

## 范围

- 采用大窗口优先的三栏布局：左侧项目导航、中间共享终端区、右侧 CLI 启动与会话恢复区；中间不显示项目标题栏。
- 左侧支持项目名称搜索、置顶、添加和项目菜单操作；新增/编辑使用弹窗，编辑可重命名并保留路径，列表行不显示路径。
- 右侧按当前目标项目提供三枚独立的内置 CLI 启动按钮和跨 CLI 合并历史会话恢复；普通启动不接受自定义参数或模型覆盖，也不提供外部终端入口或命令预览。
- 中间按 session ID 管理跨项目 PTY 会话标签；支持一个项目多个 CLI/同一 CLI 多开、横纵分栏、手动拖动比例与焦点切换。
- 点击项目只改变启动/恢复目标并突出显示其关联标签和分栏；其他项目会话继续留在共享工作区并保持可操作。
- 执行任务、设置、关于沉到侧栏底部图标；适配托盘显示、窗口关闭确认、PTY 持续运行与重新打开行为。
- M2 布局状态仅在应用运行期有效，不保存命名布局；保存、恢复和已结束会话占位由 M3 完成。
- 当前只验收 Windows；macOS/Linux 实机对齐按[跨平台对齐待办](cross-platform-alignment.md)安排在 Windows M1–M4 完成后执行，并纳入 M5 门禁。

## 非目标

- 不提供通用 IDE 式任意插件面板或拖放式窗口系统；仅支持终端分栏。
- 不在 M2 保存/加载命名布局预设或跨重启恢复 PTY 布局。
- 不改变三项 CLI 的安装、更新与认证逻辑；不再暴露自定义启动参数或模型选择。

## 验收条件

- [ ] Windows 应用以大窗口工作台启动；首次使用显示添加/选择项目入口，不自动启动 CLI；中央终端区不显示项目标题。
- [ ] 左侧只展示项目名称；名称搜索、添加弹窗、编辑重命名弹窗、置顶、打开目录和移除操作均可用，移除不会删除磁盘目录或误结束活动 PTY。
- [ ] 右侧三枚 CLI 启动按钮按检测状态启用/禁用并直接启动内置 PTY；历史列表合并三项 CLI 并按最近活动排序，恢复创建独立 PTY、验证项目归属且仅携带 CLI 必需恢复参数；普通启动不应用旧全局/项目参数，也不显示外部启动或命令预览。
- [ ] 同一项目可启动多个同 CLI PTY；多个项目、三个 CLI 会话可同时出现在同一工作区，输入、输出、尺寸、关闭和错误均按 session ID 隔离。
- [ ] 全局标签可定位会话；未显示会话可放入当前聚焦分栏；横向/纵向分栏及拖动比例有效，同一 PTY 不会被重复挂载或误终止。
- [ ] 左侧选中项目会高亮所有相关会话标签/分栏并设为启动目标，不隐藏、重排或关闭其他项目的会话；聚焦会话后项目上下文与右侧历史同步。
- [ ] 拆分后每个终端实际尺寸始终在安全边界内；空间不足时阻止继续拆分/显示明确提示，不提交零尺寸或危险尺寸。
- [ ] 窄窗口、常规窗口和最大化窗口均可使用主要操作；右侧面板和左侧导航按空间折叠，终端仍可输入与滚动。
- [ ] 执行任务、设置和关于以底部图标访问，提示、无障碍名称和任务角标正确；辅助页面往返不卸载运行中的 PTY。
- [ ] 托盘隐藏/恢复、窗口退出取消/确认及应用退出符合 M0 PTY 生命周期契约。

## 产物

- 左侧项目维护弹窗与底部图标导航。
- 跨项目会话标签、分栏树和可拖动比例的工作区 UI。
- 右侧 CLI 启动与历史会话恢复区。
- 自定义参数移除与旧配置兼容策略。

## 设计决策

- 主窗口默认尺寸为 1360×860，保留现有最小窗口尺寸；窄窗口优先折叠右侧启动/历史面板，再压缩左侧项目区。
- React 以 session ID 索引 PTY 元信息，以 split tree 维护每个可见终端面板；Rust 继续拥有真实 PTY。创建、焦点、缩放和退出均以 session ID 路由。
- 全局标签是已创建 PTY 的入口；split tree 只引用可见会话。会话标签未显示时仍保持运行，放入另一分栏不创建重复 PTY。
- PTY 运行期间保留其终端模拟器实例与屏幕缓冲；隐藏标签不发送零尺寸调整，重新显示后才按可见分栏重新测量并更新目标会话尺寸。
- 每项目会话默认标题按项目名称、CLI、序号生成；手动名称与生成标题区分，项目重命名只更新生成标题。
- 点击项目不替换全局工作区，而是更新目标项目并高亮相应会话；聚焦会话则同步当前项目上下文。
- 右侧面板在宽窗口默认展开，窄窗口自动收起；启动/恢复目标始终明确显示项目名称。
- PTY 不变量、退出与托盘行为延续 M0/M1；M2 不持久化当前分栏树，布局持久化归属 M3。
- 自定义全局/项目参数及模型选择全部从当前 UI 和启动链移除；已有数据库记录不删除但不执行，旧 JSON 配置导入忽略它们，新导出不包含它们。

## 测试与门禁计划

- 前端：运行 `pnpm run build`，检查 TypeScript、React 组件和打包产物；仓库当前无前端交互测试运行器，交互行为按 Windows 手工矩阵验收。
- Rust：运行 `cargo test --manifest-path src-tauri/Cargo.toml`、`cargo fmt --manifest-path src-tauri/Cargo.toml --check`、`cargo check --manifest-path src-tauri/Cargo.toml`；覆盖同项目多会话、项目归属、事件路由、尺寸边界、退出和旧配置参数忽略。
- 项目维护：添加/取消/校验目录，名称默认值和自定义名，重命名持久化，路径不变；置顶、打开目录、移除、活动 PTY 阻止移除；名称搜索与长名称显示。
- 多会话隔离：至少两个项目和三个 CLI 启动 PTY，并在同一项目同一 CLI 启动两个 PTY；逐一验证输入、输出、CLI 状态、尺寸更新、错误和关闭只作用于目标 session ID。
- 标签/分栏：全局标签定位与切换、未显示标签进入聚焦分栏、空分栏启动/恢复、同一 PTY 不重复呈现；横纵拆分、拖动比例、合并分栏后会话仍能从标签访问。
- 项目联动：点击项目只更新启动目标和关联高亮，不隐藏其他项目会话；聚焦终端后当前项目与右侧历史上下文同步；由右侧启动/恢复的 PTY 归属目标项目。
- 尺寸与终端：最大化、常规、窄窗口及逐步缩小分栏；PTY 尺寸不得为零或超出安全边界；隐藏标签恢复、中文输入、系统文本剪贴板双向复制、Claude Alt+V 与 Codex Ctrl+V 图片粘贴、TUI 滚动和终端输出压力下仍可用。
- 启动与恢复：确认三个按钮分别只在对应 CLI 可用时启用，普通启动不读旧全局/项目参数且无外部启动/命令预览；三项 CLI 历史合并排序、各自分页，恢复时仅携带对应内部参数并拒绝跨项目 session ID。导入旧配置忽略参数，新配置导出不包含参数。
- 导航与生命周期：辅助页往返、底部图标提示/键盘无障碍名称和任务角标、托盘隐藏与恢复、退出取消/确认、多 PTY 同时退出、PTY 启动失败。
- 真实 CLI 手工验证 Claude Code、Codex、Antigravity 各自启动、输入、并行运行、恢复会话、关闭确认；记录 CLI 版本和无法验证项。
- 代码审查覆盖需求、PTY/会话/布局生命周期、数据迁移、安全尺寸、错误恢复和文档一致性；修复后复审，再完整重跑全部自动门禁和受影响手工矩阵。未通过门禁前不得提交或宣告 M2 完成。
