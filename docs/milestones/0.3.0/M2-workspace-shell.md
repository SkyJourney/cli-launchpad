# M2：大窗口工作台与项目切换

**状态：** 待开始
**依赖：** M1
**目标：** 将主窗口从小型启动面板改为项目和终端优先的工作区。

## 范围

- 采用大窗口优先的尺寸和布局，支持常见桌面分辨率与窗口缩放。
- 建立项目导航区、中央终端工作区和可按需打开的上下文区。
- 项目导航可搜索、切换并显示每个项目的活动终端数量与 CLI 类型。
- 项目切换只改变当前工作区上下文；其他项目的 PTY 保持运行和可再次进入。
- 安装更新、CLI 状态、参数、备份、任务历史和关于页保留清晰入口，不抢占终端主画布。
- 更新托盘显示、窗口关闭与重新打开行为以适配工作台。

## 非目标

- 不在本阶段引入任意布局树或工作区快照。
- 不重做 CLI 管理逻辑，优先接入现有 Rust service 和数据库。

## 验收条件

- [ ] 应用启动进入大窗口工作台，终端是主内容区。
- [ ] 项目切换不创建重复 PTY，也不关闭未选项目的活动终端。
- [ ] 窄窗口、常规窗口和最大化窗口均可使用主要导航与终端操作。
- [ ] 辅助能力可从工作台进入，返回后选中项目和终端上下文仍在。
- [ ] Windows、macOS、Linux 均能正确显示、隐藏并重新聚焦主窗口。

## 产物

- 新版应用主框架和项目导航。
- 保留现有项目、设置和任务管理功能的迁移清单。
