# 0.3.0 跨平台对齐待办

**状态：** 准备开始；Windows M1–M4、G1–G4 已完成
**所属版本：** 0.3.0
**范围：** macOS 与 Linux 实机验证、平台适配和最终发布门禁

Windows 本地 0.3.0 x64 NSIS 候选包已完成干净构建、安装升级和启动验证。macOS/Linux 对齐是当前剩余的版本工作；完成后再决定正式 tag 和多平台发布。

## 执行顺序

0.3.0 先在 Windows 上完成 M1–M4、独立 G1–G4 的实现、验收和复核，再集中在 macOS/Linux 设备上对齐平台差异。此文档是 M1–G4 所有 macOS/Linux 实机验收项的唯一执行清单；各里程碑文档保留平台设计事实和范围边界，并链接到此处，不重复维护验收清单。实机事项不阻塞 Windows 阶段推进，但必须在 M5 发布验收前完成，或逐项记录明确的延期决定。

## 分阶段任务

每个平台独立记录和验收；可按设备可用性选择先后，不以一个平台的结果替代另一个平台。

1. **建立目标机基线：** 记录系统/桌面环境、CPU 架构和工具链；运行 Tauri 配置校验、Rust 测试与目标平台 Release 编译、前端构建，先解决阻塞构建的问题。
2. **补齐平台实现：** 优先按官方文档完成 Hermes 在该平台的安装、版本/更新策略和来源保护；复核五项 CLI 的可用性探测、PTY 启动/恢复参数和历史数据路径，并补充平台单测。
3. **验证工作台交互：** 按共通清单验收 PTY 生命周期、输出/输入、窗格与布局、主/独立窗口、主题同步、项目/会话状态和异常恢复；修复平台差异后回归。
4. **打包和升级验收：** 构建平台产物，在目标桌面实际安装、启动、升级旧数据并验证图标、依赖、托盘和卸载/重装行为；记录证据或逐项延期理由。

阶段 1 的实际目标编译通过后再进入阶段 2；阶段 2/3 的缺陷闭环后再执行阶段 4。CI 产物可辅助验证打包，但不能替代各平台的交互和安装检查。

## 共通验收项

- [ ] 确认操作系统版本、CPU 架构、应用版本/构建和五个 CLI 的版本，并记录测试环境。
- [ ] 执行 macOS/Linux Tauri 配置、目标平台依赖/schema、Rust 编译和前端打包门禁；通过 CI 或对应平台主机验证实际 release target。逐项记录未能在 Windows 主机执行的检查，不以 Windows 构建代替。
- [ ] 对目标机器上已安装且获准使用的 CLI，在指定项目目录逐项验证 PTY 启动、输入、输出和正常退出；每个平台至少完成一项真实交互启动。未安装的 CLI 记录其检测/计划测试证据，不为验收擅自执行安装。
- [ ] 验证 Grok 官方安装与更新来源、`GROK_BIN_DIR`/默认路径探测、项目会话摘要读取、本地搜索及 `--resume` 恢复。
- [ ] 接入并验证 Hermes 官方平台安装方式、源码/包管理更新所有权、版本/更新来源校验、活动 Hermes home 的只读会话库读取、项目过滤和 `--resume` 恢复；若官方渠道不支持目标平台，作为范围决策单独记录。
- [ ] 验证终端列行尺寸变化、中文/Unicode 输入、ANSI 色彩、全屏 TUI、滚动、复制粘贴和快捷键。
- [ ] 验证高输出期间界面响应、输出回压、单会话关闭、异常终止和进程树清理。
- [ ] 验证应用退出确认/取消、托盘或平台对应的后台行为，以及退出后旧 PTY 记录修正。
- [ ] 验证 G3 自定义标题栏跨平台外观、窗口控制、拖动/缩放和主/独立窗口生命周期一致性。
- [ ] 验证项目归属、运行会话期间阻止删除项目，以及启动失败时的明确错误状态。
- [ ] 验证 M1/M2 PTY 与共享工作区：进程树清理、会话归属、窗格拖动、独立窗口交接、项目切换/删除保护和空窗格保留。
- [ ] 验证 G1/G2 五 CLI 适配：安装/更新计划来源、版本状态、项目历史/搜索/恢复、Hermes 当前有效 home/Profile 数据源隔离；不要求执行会改变设备的安装或更新，除非用户另行安排。
- [ ] 验证 M3/G4 布局与状态：布局保存/恢复、标签/焦点/pane 比例、主题偏好、系统主题解析以及主窗口到多个独立窗口的同步和新窗口初始化。
- [ ] 验证 G4 适配器能力矩阵和错误隔离：缺能力或数据源失败显示 unknown/error/incomplete，不伪装成无会话/无更新；单 CLI 故障不影响其他 CLI 或 PTY。
- [ ] 对照 G4 全局 CSS 语义 token 矩阵检查 macOS/Linux 控件、窗口标题栏和 Toast；终端 ANSI、日志和品牌素材按既定例外处理。
- [ ] 对照 Windows 已验收行为记录平台差异；仅为平台差异补适配，不改变已确认的产品范围和生命周期契约。
