# 0.3.0 跨平台对齐待办

**状态：** 待 Windows 版 M1–M4、G1 与 G2 完成后启动
**所属版本：** 0.3.0
**范围：** macOS 与 Linux 实机验证、平台适配和最终发布门禁

## 执行顺序

0.3.0 先在 Windows 上完成 M1–M4、独立 G1 和 G2 的实现、验收和复核，再集中在 macOS/Linux 设备上对齐平台差异。此文档中的实机事项不阻塞 Windows 阶段推进，但必须在 M5 发布验收前完成，或逐项记录明确的延期决定。

```mermaid
    win["Windows 完成 M1–M4、G1 与 G2"] --> align["macOS/Linux 实机对齐"] --> m5["M5 跨平台发布验收"]
```

## 共通验收项

- [ ] 确认操作系统版本、CPU 架构、应用版本/构建和五个 CLI 的版本，并记录测试环境。
- [ ] 在指定项目目录分别启动 Claude Code、Codex、Antigravity、Grok Build、Hermes Agent；验证终端输入、输出和正常退出。
- [ ] 验证 Grok 官方安装与更新来源、`GROK_BIN_DIR`/默认路径探测、项目会话摘要读取、本地搜索及 `--resume` 恢复。
- [ ] 验证 Hermes 官方平台安装方式、源码/包管理更新所有权、活动 Hermes home 的只读会话库读取、项目过滤和 `--resume` 恢复。
- [ ] 验证终端列行尺寸变化、中文/Unicode 输入、ANSI 色彩、全屏 TUI、滚动、复制粘贴和快捷键。
- [ ] 验证高输出期间界面响应、输出回压、单会话关闭、异常终止和进程树清理。
- [ ] 验证应用退出确认/取消、托盘或平台对应的后台行为，以及退出后旧 PTY 记录修正。
- [ ] 验证项目归属、运行会话期间阻止删除项目，以及启动失败时的明确错误状态。
- [ ] 对照 Windows 已验收行为记录平台差异；仅为平台差异补适配，不改变已确认的产品范围和生命周期契约。

- [ ] 验证 macOS 安装包启动、升级 0.2.4 用户数据和统一品牌图标。
- [ ] 记录必要的平台代码、权限、打包配置或 UI 适配及其复测结果。
