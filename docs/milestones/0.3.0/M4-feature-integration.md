# M4：现有能力接入与数据迁移

**状态：** 待开始
**依赖：** M2、M3
**目标：** 让 0.2.4 用户熟悉的核心能力继续服务新工作台。

## 范围

- 将 CLI 本机状态、当前/最新版本和安装更新入口接入新设置区。
- 保留后台执行任务、实时日志、取消、历史记录和版本回读行为。
- 从右侧项目上下文展示三项 CLI 的历史会话，支持恢复、别名和独立 PTY 启动；新 PTY 接入 M2 全局共享工作区。
- 保留配置导入导出、SQLite 备份恢复与诊断导出；配置 bundle 不再暴露自定义 CLI 参数或模型选择。
- 迁移已保存的项目、CLI 配置、别名、窗口设置和 M3 布局；旧版全局/项目参数记录保留但不参与启动，旧配置导入忽略参数字段。
- 0.3.0 普通 CLI 启动统一使用内置 PTY；启动失败显示明确错误，不提供外部终端备用启动入口。

## 非目标

- 不在应用中复制 CLI 的认证、额度或会话正文存储。
- 不改变官方安装来源和三项 CLI 的产品范围。

## 验收条件

- [ ] 从 0.2.4 升级后项目、会话别名、设置及备份均保留；旧参数数据不执行。
- [ ] 三项 CLI 均可在项目内查看历史并按 CLI 原生机制恢复。
- [ ] 安装更新任务能从工作台发起，并在后台任务视图中查看状态和日志。
- [ ] 配置导入、导出、备份、恢复和诊断导出仍可通过 UI 使用。
- [ ] 从工作台离开并返回辅助功能后，项目和会话上下文不丢失。

## 产物

- 旧版功能到新工作台的信息架构映射。
- 数据库迁移与回滚说明。
- 主要能力的端到端人工验收记录。
