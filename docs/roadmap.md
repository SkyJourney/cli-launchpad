# Roadmap

## Phase 1: Launchable MVP

- Apply SQLite migrations at app startup.
- Add directory CRUD commands.
- Add tool and shell profile CRUD commands.
- Implement command preview.
- Implement Windows launch through Windows Terminal and PowerShell.

## Phase 2: Usability

- Directory search and pinning.
- Recently used sorting.
- Drag-and-drop folder import.
- Per-directory tool argument editor.
- Command copy button.
- Startup validation for missing tools or deleted directories.

## Phase 3: Desktop Polish

- System tray quick launch.
- Window state persistence.
- Import/export configuration.
- Update workflow.
- macOS/Linux launch helpers.
